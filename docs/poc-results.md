# POC 검증 기록

## iOS 네이티브 POC 구현 검증 — 2026-11-04

기준: 현재 작업 트리. 앱·온보딩 5단계·월별·위젯·Live Activity 소스를 구현했으며, Apple SDK 빌드와 실기기 실행은 아직 하지 않았습니다. 구현과 실제 수집 성공은 구분합니다.

| 상황 | 기대 동작 | 검증·결과 |

실행 환경: Windows Docker Desktop의 `swift:6.0` Linux 컨테이너(Swift 6.0.3).

```sh
docker run --rm -v "$PWD/Core:/pkg" -w /pkg swift:6.0 swift test
docker run --rm -v "$PWD:/repo" -w /repo swift:6.0 bash scripts/check-storage.sh
docker run --rm -v "$PWD:/repo" -w /repo swift:6.0 bash scripts/check-ios.sh
```

- Core: **25개 통과, 실패 0개**. 저장소: **10개 통과**. 공통 금액 입력·표시: **3개 통과**. 모든 iOS Swift 파일 문법 검사 통과.
- 리팩토링: 날짜 이월·빈 날짜 채우기·지난달 비교를 private 메서드로 분리하고, 금액 표시·신분/기준 입력을 공통화했습니다. 앱의 중복 재조회와 무의미한 저장 옵션을 제거하고 월별 화면의 강제 해제를 없앴습니다. 공개 Core 인터페이스와 저장 형식은 유지했습니다.
- 발견·수정: 읽기만 하는 위젯에서도 날짜 변경·보관 기간 정리를 파일에 반영하도록 수정하고 회귀 검사 추가. 저장 실패 검사 초기 버전은 상태 변경이 없어 쓰기가 생기지 않았으므로 실제 변경 후 쓰기를 실패시키도록 검사 자체를 교정했습니다.
- 독립 소스 검토에서 위젯의 미연결 URL을 제거하고 기본 앱 열기를 사용하도록 수정했습니다.
- macOS CI에 XcodeGen 생성·서명 없는 시뮬레이터 빌드를 추가했으나 원격 CI는 실행하지 않았습니다. Linux 검사는 SwiftUI·ActivityKit의 Apple SDK 타입 검사를 대신하지 않습니다.
- 다음 검증: Apple SDK 빌드 → TestFlight 준비·설치 → 온보딩·가짜 본문 Intent·월별·잠금화면 → 다음 평소 KB 결제에서 실제 수집. 신규 결제는 요구하지 않습니다.
- 알려진 제한: 중복 알림을 구분하지 못함, KB 취소 형식 미확인, 기기 날짜를 과거로 돌리면 접힌 날짜는 합계만 복원되어 개별 취소 대조 불가. iOS 파일 보호·Live Activity 동시 갱신 순서는 기기 미검증입니다.

## 판정

- 수집 POC: **미검증**
- Flutter 앱 구현 진입: **대기 — 두 결제 유형의 수신·승인 금액·취소 구분 근거 필요**
- 실패·미지원 조건: 아직 미확인
- 실제 계좌·카드·금액·상점·알림 원문은 기록하지 않습니다.

중복 제거, 원거래 대조, 날짜 초기화, 저장·복구, Live Activity는 앱 단계의 검증 대상이며 현재 통과하지 않았습니다.
