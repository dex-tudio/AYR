# AYR 디자인 개편

2026-11-07: 사용자가 선택한 **개성 있는 브랜드 앱 / 크림·잉크·라임 / 전체 화면과 위젯** 방향을 반영했다. 화면 실행 검증은 아직 완료하지 않았다.

## 레퍼런스

GitHub 조회 시 표시된 별 수이며 전체 인기 순위나 디자인 품질 점수는 아니다. 코드·이미지는 가져오지 않았다.

공통 테마는 `iOS/Shared/AYRTheme.swift`에서 앱과 위젯이 공유한다. 저장 형식·수집·집계·설정 저장·삭제 확인 로직과 앱 아이콘은 유지했다. 외부 의존성은 추가하지 않았다.

## 검증 결과

- Docker Swift 6.0: Core 테스트 50개 통과. 기존 캐시의 마운트 경로 충돌로 첫 실행은 실패했으며, `swift test --package-path Core --scratch-path /tmp/ayr-core-tests`로 재실행해 통과했다.
- `scripts/check-ios.sh`: 금액 입력·표시 검사 3개와 전체 iOS Swift 문법 검사 통과. Apple SDK 타입 검사는 포함하지 않는다.
- 공통 팔레트의 라이트·다크 글자/배경 조합 20개와 잉크/라임 버튼 조합 1개를 대비 공식으로 계산해 모두 4.5:1 이상 확인했다. 기본 팔레트 글자/배경 조합의 최솟값은 5.77:1이다. 시스템 틴트·투명도·보조 텍스트까지 확인한 결과는 아니다.
- 별도 에이전트 정적 검토에서 확정적인 타입 오류·수신/저장 회귀는 발견하지 못했다. SDK 빌드 통과를 의미하지 않는다.

## Apple 실행 환경에서 확인할 항목

아래 항목은 모두 **미검증**이다. Windows에서 실제 앱 화면 비교 이미지도 생성하지 못했다.

| 상황 | 기대 결과 | 확인 방법 |
| --- | --- | --- |
| 작은 화면·큰 글자·키보드 | 온보딩 입력과 이전/다음 버튼에 접근 가능 | iPhone 시뮬레이터/실기기에서 5단계 진행 |
| 0원·주의·초과·최대 금액 | 금액·문구가 겹치지 않고 상태 전달 | 위젯 파일의 가짜 데이터 `#Preview` 및 앱에서 확인 |
| 빈 기록·0원·미래 날짜 | 월별 달력에서 의미 구별 | 월별 화면 확인 |
| 수신 실패·초기 설정 필요 | 오류 안내와 재시도/설정 진입 유지 | 앱과 위젯 확인 |
| 날짜 만료 | Live Activity에 새로고침 안내 | 만료된 날짜의 `#Preview` 확인 |
| 단색·틴트 잠금화면 위젯 | 색 없이도 금액·문구가 읽힘 | 실제 잠금화면 확인 |
| 설정 저장·지출 추가/삭제·자동 수신 | 오늘·월별·위젯에 같은 합계 반영 | 테스트용 데이터/자동화로 연속 실행 |

앱·위젯의 Apple SDK 빌드와 실기기 화면 확인 전까지 디자인 검증은 미완료다. 커밋·푸시·TestFlight 배포는 하지 않았다.
