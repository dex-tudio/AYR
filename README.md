# 님 부자임? — AYR

사용자 금융정보 연결·동의 → 서버가 금융 API로 거래 수집 → 오늘 합계·신분별 문구 계산 → PWA 화면·웹 푸시 갱신을 목표로 합니다.

## 현재 진행

1. [MVP 확정 명세](docs/mvp-spec.md): 사용자 선택과 PWA 전환 방향.
2. [금융 API 검토 기록](docs/financial-api-review.md): 후보·지원 범위·미확인 조건·제공사 확인용 문의 초안.

현재는 실제 데이터 제공사를 선정하는 단계입니다. CODEF·HYPHEN·오픈뱅킹을 검토했으나 토스페이·토스뱅크 체크카드의 당일 승인·취소와 이용 자격을 모두 확인한 제공사는 아직 없습니다.

## 범위와 상태

- 단축어 POC와 Flutter 앱 개발 경로는 중단했습니다. 이전 POC 문서는 조사 기록으로만 보관하며 사용자가 실행할 필요는 없습니다.
- 개발·검증은 무료 우선이며, 유료 운영·사업자 계약도 검토 가능합니다.
- 실제 금융 데이터 접근·PWA 서버 구현·웹 푸시 수신은 아직 미검증입니다. 앱 코드와 빌드·테스트 명령은 아직 없습니다.
- 모의 데이터로 작동하는 화면을 실제 금융 연동으로 표시하지 않습니다.
- 실제 서버를 만들 때 사용자별 인증·접근 제어와 안전한 자격증명 보관을 포함합니다.
- 가입·계약·결제·문의 발송·커밋·푸시·배포는 별도 요청 없이 실행하지 않습니다.
