# 금융 API 실데이터 경로 검토

확인일: 2026-11-03. 상태: **공개 문서·상품별 스키마 조사 완료, 실데이터 접근과 운영 제공사 선정 전**.

## 조사 결론

- 결제 발생 확인 자체는 가능합니다. 카드 승인내역에서 승인번호·일시·금액·취소 상태를 조회하는 구체 API를 확인했습니다. 다만 모든 금융서비스의 결제 순간을 무조건 통보하는 범용 이벤트 API를 확보한 것은 아닙니다.
- **무료 실데이터 POC 우선 후보는 CODEF**입니다. 실제 데이터 데모 1개월·일 100회가 공식 요금 안내에 명시되어 있습니다. 샌드박스와 구분해야 합니다.
- **소비자 서비스 운영 구조의 제휴 상담 우선 후보는 쿠콘**입니다. 2026년 회사 사업보고서에 마이데이터 미인가 기관 대상 제휴 사업을 명시합니다. 원시 거래를 우리 서버에 전달하는 방식인지, 쿠콘 화면 연동만 제공하는지는 미확인입니다.
- 하이픈은 실제 개인 승인·부분취소 스키마를 확인했으나 월 멤버십·건별 과금과 금융기관 인증 흐름이 필요합니다. 현재 무료 검증 범위는 재확인이 필요합니다.
- 데이터허브는 개인 신청과 무료 테스트 50회를 명시하지만, 확인한 승인내역 문서는 법인카드 상품입니다. 소비자 가계부 적합성은 별도 확인해야 합니다.
- 토스페이·토스뱅크 체크카드를 모두 지원하고, 모바일 웹 연결 및 15분 이내 갱신까지 보장하는 공급선은 아직 확인하지 못했습니다.

‘개인 회원 가입 가능’, ‘개인카드 데이터 제공’, ‘타인의 금융정보를 처리하는 소비자 서비스 운영 가능’은 서로 다른 조건입니다. 일반 가입 약관만으로 세 가지가 모두 충족됐다고 판단하지 않습니다.

## 목표와 조건

- 사용자 연결·동의 후 서버에서 실제 소비를 수집하고 PWA 화면과 푸시를 갱신합니다.
- 사용자가 금융 앱 알림이나 단축어를 설정하지 않는 흐름을 목표로 합니다.
- 개발·검증은 무료 우선, 유료 운영·사업자 계약도 검토 가능합니다. 아직 유료 신청·계약·문의 발송을 실행하지 않았습니다.
- 희망 범위는 토스페이 온라인 결제와 토스뱅크 체크카드입니다. 다른 금융사로 범위를 자동 변경하지 않습니다.
- 사용자는 갱신 지연을 **최대 15분**까지 허용했습니다. 제공사가 이를 보장한다는 뜻은 아니며 실제 조회 지연·허용 주기 검증이 필요합니다.

## 확인한 후보

| 후보 | 확인한 사실 | 미확인 사항과 판단 |
| --- | --- | --- |
| CODEF | 개인 승인내역 API `/v1/kr/card/p/account/approval-list`. 실제 데이터 데모 1개월·일 100회(일부 제휴 API 제외). 정식 가격은 별도 상담, 호출량 과금. | 무료 POC 우선 후보. 토스는 공식 개인카드 상세 시트에서 확인되지 않았습니다. 과도한 호출·배치형 사용 제한과 기관별 취소 누락이 있어 15분 정기 갱신을 바로 약속할 수 없습니다. |
| HYPHEN | 스크래핑 개인카드 조회 상품(seq=90), 승인 조회 `/in0007000545`와 선택 부분취소 필드 확인. TR슬림 월 멤버십 10만원 + 건별 정상요금. 약관은 멤버십 11만원(VAT 포함), 시그니처는 상품 페이지 월 기본료 30만원부터 안내. | 금융기관 ID/PW 또는 인증서 기반 인증. 해당 상품 코드집에 토스 미등재(최신 미지원으로 단정하지 않음). 소비자 서비스 운영 자격·정확 단가·15분 갱신은 미확정. |
| 쿠콘 | 2026년 회사 사업보고서에 미인가 기관 대상 마이데이터 제휴 사업을 명시. 공식 브로슈어의 Plug-In 사례는 자산관리 화면을 WebView로 연동합니다. | 운영 제휴 상담 우선 후보. 자체 합계·문구·푸시를 위해 서버에서 거래를 받을 수 있는지, 토스 범위·스타트업 계약·최소 비용·갱신 지연은 미확정. |
| 데이터허브(MDH) | 공식 FAQ는 개인 신청 가능, 무료 테스트 50회와 추가 신청, 정식 1년 계약 및 도입비·월 비용을 안내. | 확인한 승인내역 상품은 법인카드 Basic이며 사업자번호를 요구합니다. `CARD_TYPE=P` 필드만으로 소비자용 적합성을 판단하지 않습니다. 토스 지원·테스트 실데이터 여부·갱신 주기 미확정. |
| 금융결제원 오픈뱅킹 | 이용기관은 이용계약과 승인이 필요합니다. 계좌 거래내역·카드 청구상세 등 API가 공개 안내되어 있습니다. | 계좌 출금이나 청구내역이 당일 소비 승인·취소를 모두 제공한다고 보장하지 않습니다. 이용 자격·수집 지연·원하는 두 결제 유형의 범위를 확인해야 합니다. |
| 토스페이먼츠/토스페이 가맹점 결제 API | 자기 가맹점에서 생성한 결제를 승인·조회하는 흐름입니다. | 사용자의 다른 가게 소비를 모두 가져오는 경로로 채택하지 않습니다. |
| 바로빌·팝빌 | 바로빌은 개인카드 구분을 지원하지만 사업자번호·카드사 ID/PW와 자동 수집 주기 6시간/1일을 안내. 팝빌 공개 개발자센터는 카드조회 준비 중 표시. | 현재 15분 이내 소비 갱신 요구의 우선 후보에서 제외합니다. 계좌 조회 지원·고객사 로고를 개인 승인내역 지원 근거로 사용하지 않습니다. |

## 앱인토스(토스 미니앱) 검토

- **소비내역 API 없음:** SDK `User.getConsentedData`의 타입 목록에 `USER_CONSUMPTION_HISTORY`가 있지만, 2026-10-12 운영진 답변은 "현재 제공하고 있지 않"고 "아직 정해진 시점은 없"다고 안내합니다. 목록 존재를 제공 근거로 쓰지 않습니다.
- **나머지 제공 API:** 토스 로그인, 동의 기반 이름·전화번호·이메일 등 기본 정보, 토스 인증(CI), 서버 발송 기능성 푸시(제목 7자·본문 25자, 템플릿 검수, 광고·리텐션 문구 불가, 야간 대량 발송 보류), 인앱결제·토스페이(자기 서비스 결제용).
- **카테고리:** 토스는 2026-08-27 업데이트에서 가계부·소비 분석을 '재테크' 탭 대상 서비스로 명시했습니다. 가계부 미니앱 입점 자체는 허용되는 범주입니다.
- **유사 서비스:** 앱인토스 안에서 토스 결제 내역을 자동 반영하는 가계부 미니앱은 찾지 못했습니다. 구독료 관리 미니앱 등 수동 입력형 사례만 확인했습니다. 앱인토스 밖에서는 '소비의온도'(2026-09 출시 독립 앱)가 카드 결제 문자·알림 연동으로 자동 기록합니다. 이는 현재 제외한 네이티브 알림 수집 방식입니다.
- **판단:** 미니앱으로 만들어도 토스의 소비 데이터를 받을 수 없어 핵심 가설(자동 반영)을 해결하지 못합니다. 데이터는 여전히 외부 금융 API가 필요하며, 앱인토스는 로그인·푸시·노출 채널 후보로만 남깁니다. 외부 금융 API 연동이 미니앱 정책상 허용되는지는 미확인입니다.

### 앱인토스 시나리오

| 단계 | 현재 가능한 흐름 | 근거·제약 |
| --- | --- | --- |

| 연결 해제 | 토스에서 연결 끊기 → 미니앱 사용자 데이터 삭제 | 체크리스트 필수 항목. 우리 명세의 철회 시 삭제와 일치 |

- 토스 소비내역이 제공되면 '금융 연결' 단계가 토스 동의 1회로 바뀌어 외부 금융 API·카드사 인증이 필요 없어집니다. 현재 미제공·일정 미정입니다.
- 정책상 금지인 '금융 상품'은 대출·보험·카드·증권 판매입니다. 가계부·소비 분석은 토스가 재테크 범주로 안내합니다.
- 개인 개발자 입점 가능 여부와 사업자 요건은 이번 조사에서 확인하지 못했습니다.
- 앱인토스 전용으로 만들면 토스 밖(일반 브라우저 PWA) 사용자는 별도 경로가 필요합니다. 공통 서버를 두고 화면만 분리하는 구성이 가능하지만 범위 결정이 필요합니다.

## 실제 확인한 계약과 주의할 차이

### CODEF

- 공식 가이드의 공개 문서 응답에서 승인 API 경로와 입출력 명세를 확인했습니다. 조회 타임아웃 300초는 갱신 주기나 응답 보장이 아닙니다.
- 연결 인증수단 `connectedId`를 재사용하며 공동인증서 또는 금융기관 ID 로그인을 사용합니다. 기관별 추가 카드 정보·SMS 인증이 있을 수 있습니다. 동의 버튼 하나로 끝나는 연결 UX로 가정하지 않습니다.
- `resCancelYN`은 정상/취소/부분취소/거절을 구분하지만 기관별 데이터 한계가 있습니다. 예를 들어 신한 부분취소금액 미제공, 롯데 해외 부분취소 미제공 설명이 있습니다.
- 공식 카드별 상세 시트에는 KB·현대·삼성·NH·BC·신한 등 지원 카드사가 있지만 토스는 확인되지 않았습니다. 목록 미기재를 최신 미지원 확정으로 해석하지 않습니다.
- 정식 단가는 공개 숫자를 찾지 못했습니다. 무료 데모의 가입 승인·해당 상품 적용 여부·실제 금융조회는 아직 실행하지 않았습니다.

### HYPHEN

- 개인카드 조회 상품은 스크래핑입니다. 마이데이터 연결 상품의 인증 방식과 혼동하지 않습니다. 일반 호출자 OAuth 토큰과 소비자의 금융기관 인증도 별개입니다.
- 공개 OpenAPI의 승인 응답에는 이용일·시간·승인번호·이용금액과 선택 승인상태·부분취소금액이 있습니다. 필드가 선택 사항이므로 모든 기관에서 값이 제공된다고 가정하지 않습니다.
- 무료 테스트 일/월 한도에 대한 일반 가이드가 연결하는 이벤트는 2022-10-31 종료로 표시됩니다. 종료 안내는 충전·테스트 건별 과금 가능성을 명시하므로 현재 무료 조건으로 사용하지 않습니다.
- 2025-02-03 상품별 코드집의 개인카드·개인은행 시트에 토스가 없습니다. 통합 기관코드에 토스뱅크 코드가 있다는 사실은 개별 상품의 토스 지원 근거가 아닙니다.

### 조회 주기와 무료 한도

사용자 1명·조회 상품 1개를 15분 간격으로 하루 종일 한 번씩 호출하면 하루 96회입니다. 이는 산술 예시이며 CODEF의 정기 호출 허용이나 15분 갱신 보장이 아닙니다. 인증·초기조회·추가 페이지·재시도·다중 카드사 호출은 별도로 한도와 비용을 확인해야 합니다.

Orbit 공개 API 검색도 수행했으나 결제 실행·가맹점 API만 반환되어 적합한 후보를 선택하지 않았습니다. 검색 실패는 실제 API가 없다는 뜻이 아닙니다.

Postman CLI 1.82.0은 사용 가능하지만 로그인·워크스페이스 초기화는 되어 있지 않습니다. 외부 워크스페이스 생성·게시·샘플 금융정보 업로드는 하지 않았습니다.

## 제공사 확인용 문의 초안 — 미발송

> 소비자용 가계부 PWA를 개발 중입니다. 사용자가 모바일 웹에서 본인 금융정보 연결·동의·인증을 완료하면, 서버가 당일 소비를 가져와 오늘 합계와 문구를 계산하고 웹 푸시를 제공하려 합니다.
>
> 1. 토스페이 온라인 결제와 토스뱅크 체크카드의 개인 승인·전체/부분 취소를 조회할 수 있는 상품명과 명세를 알려주세요. 지원하지 않는 범위도 구분 부탁드립니다.
> 2. 개인 개발/사업자별 신청 조건, 소비자 대상 서비스의 계약·운영 조건과 모바일 웹 연결·동의 절차를 알고 싶습니다.
> 3. 무료 개발 환경이 모의 데이터인지 본인 실거래 조회도 가능한지, 운영 비용·최소 약정·호출 제한은 어떻게 되는지 알려주세요.
> 4. 거래 식별·원거래 취소 연결·일시·통화 필드와 증분 조회, 갱신 지연·웹훅 지원 여부를 확인하고 싶습니다.
> 5. 금융기관 인증수단과 토큰의 보관 책임, 철회·연결 해제·데이터 보관 조건을 안내 부탁드립니다.
> 6. 본인신용정보관리업 허가를 보유하지 않은 초기 개발팀이 소비자 대상 PWA로 서비스를 제공할 수 있는 제휴·위탁 구조가 있나요? 우리 서버가 거래를 받아 합계·문구를 계산하고 웹 푸시를 보내는 이용 범위도 포함되는지 확인 부탁드립니다.
> 7. 목표 갱신 지연은 최대 15분입니다. 해당 주기로 반복 조회가 허용되는지, 데이터 원천의 실제 반영 지연·재인증·한도·추가 비용을 확인 부탁드립니다.

### 후보별 확인 우선순위

1. 쿠콘: 미인가 기관 제휴에서 자체 PWA·서버 집계·푸시가 허용되는지, 화면 제공만 가능한지부터 확인.
2. CODEF: 지원 카드사 한 곳의 무료 실데이터 데모 자격·15분 반복 수집 허용·연결 인증 UX부터 확인. 토스 지원은 별도 질문.
3. HYPHEN: 월 멤버십 전에 무료 개발 테스트가 가능한지, 해당 카드 상품의 소비자 서비스 조건과 토스 지원을 확인.
4. MDH: 법인카드 API 외 소비자 개인 승인내역 상품이 있는지, 무료50회가 실제 데이터 검증을 포함하는지부터 확인.

첫 무료 POC에서 다른 지원 카드사 1곳을 허용할지는 사용자 결정 대기입니다. 정식 제공사 계약이나 비용 결제 결정은 아직 하지 않았습니다.

사용자의 명시적 요청 없이 이 문의를 외부에 보내거나 가입·계약·결제를 실행하지 않습니다. API 키·금융정보는 문의에 첨부하지 않습니다.
